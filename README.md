# DRHS Hackathon 2026 Submission

Summary of theme problem: You are transported to a time between 1000 and 3000 years ago. You do not understand the language of the time. Create an application where a user can input new words to translate to English.
Time limit: 2 hours, 30 minutes (extension was given to all teams after first 20 minutes)

Contributors: Haoyan Li, Michael Gorlanov, Seamus Gregory, Achintya Tiwari

We placed 3rd and the judges specifically highlighted our skeuomorphism-inspired dictionary-styled UI design (which was admittedly very basic but had more effort put in compared to other teams which had the same problem).
